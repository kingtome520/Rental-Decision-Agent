## 一、项目速览

- **问题**：毕业生租房时需要在“预算、通勤、房型”之间反复权衡，人工筛选 200 套房成本极高。
- **场景**：单用户多轮对话式决策助手，输入预算、公司地址和通勤上限，最终输出 3–5 套带理由与风险提示的候选。
- **差异点**：它是有状态决策图（LangGraph），而并非一次性问答 —— 缺信息会 `interrupt` 暂停追问、算不出结果会回溯放宽、还不行动转协商让用户选。
- **链路**：用户输入 → 槽位解析(L1) → 缺槽位则澄清(interrupt) → 硬约束筛选 → Haversine 粗筛 Top20 → 高德通勤精算 → 合格判定(≥2 套) → 不足则回溯≤2 次 → 超限转协商(interrupt) → 报告(L4/L5) → ID 白名单校验。
- **已完成**：`app/config.py`、`app/db.py`、`app/tools/listings.py`、`app/tools/mock.py`、`app/tools/map.py` 的 mock 分支、`app/tools/llm.py` 的 mock 分支、`app/prompts/*.md`、`app/data/listings.json`(200 条)、`eval/metrics.py`。
- **空实现（`NotImplementedError`）**：`app/graph/nodes/` 下 10 个节点中的 9 个、`app/graph/build.py` 的 6 个函数、`app/main.py` 的 3 处、`app/tools/map.py` 与 `app/tools/llm.py` 的真实 HTTP 分支、`eval/baseline.py`、`eval/run_eval.py`、`scripts/annotate_profiles.py`。
- **半成品**：`app/graph/nodes/coarse_filter.py` 写了 3 行，键名写错且**没有 return**。
- **致命阻塞**：`app/graph/state.py` 第 42 行重复 `from __future__ import annotations` → `SyntaxError`，整个图包无法 import，`pytest` 目前 **2 failed + 2 errors**。
- **离线可跑**：`.env` 已经是 `MOCK_LLM=1 MOCK_MAP=1`，**M2–M4 全程不需要任何 Key**，真实 API 是最后一步的加分项。

### 2.2 必须遵守的调用约定（违反即 Code Review 打回）

| 约定 | 具体要求 | 依据 |
|---|---|---|
| 外部调用只走工具层 | 节点内**禁止** `httpx`、禁止直接 `json.load(listings.json)`；只能 `from app.tools.map import ...` / `from app.tools.listings import ...` | `app/tools/__init__.py` 设计原则 1–3 |
| 魔法数字只从 settings 取 | 半径余量、TopK、回溯上限、默认房型，全部 `from app.config import settings`，节点里不许出现 `1.3`、`20`、`2`、`15` | `app/config.py` 第 1–5 行 |
| 节点签名与返回 | `def node(state: AgentState) -> dict`，**只返回增量**，不原地改 `state`；`state` 用 `.get(key, default)` 读 | `app/graph/nodes/__init__.py` |
| `constraints` 键名唯一口径 | `budget_max` / `commute_limit_min` / **`commute_mode`**（不是 `mode`）/ `room_type` / `max_walk_to_subway_min` | `设计.md` §6.2 `expected_slots` |
| 路由返回值与节点注册名逐字一致 | 注册 `add_node("generate_report", ...)`，路由就必须返回 `"generate_report"`，不能返回 `"report"` | `app/graph/build.py` 第 11–17 行 |
| 终止边用常量 | `from langgraph.graph import END`，`route_after_validate` 返回 `END`，不要返回 `"END"` 字符串（否则要配 `path_map`） | 同上 |

**自测习惯（三条）**

1. 每个节点写完后**直接调用**：`node({**initial_state("t"), 手工字段})`，先看返回的 dict 键对不对，再挂图 —— 挂图后的报错会被 LangGraph 堆栈淹没。
